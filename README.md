# Run Msafat — موقع سباقات

HTML + CSS + JavaScript بدون إطار عمل. خادم JavaScript بـNode.js وقاعدة SQLite.

## التشغيل على جهازك

1. ثبّت Node.js 24 أو أحدث.
2. افتح مجلد المشروع في VS Code.
3. افتح Terminal داخل المجلد الذي يحتوي على `package.json`.
4. اكتب `npm install` لتثبيت الحزم، ثم `npm run setup` واختر اسم مستخدم وكلمة مرور من 12 حرفًا على الأقل؛ كلمة المرور مخفية عند الكتابة.
5. اكتب `npm start` وافتح `http://localhost:3000`.
6. اضغط «دخول الأدمن»، أو افتح `http://localhost:3000/admin.html` وسجّل بالحساب الذي اخترته.
7. انسخ `.env.example` إلى `.env` عندما تريد إعداد خدمات الإرسال. لا يوجد اسم مستخدم أو كلمة مرور افتراضية.

ثبّت الحزم باستخدام `npm install` قبل التشغيل. تُنشأ قاعدة البيانات في `data/races.sqlite`. لا تنشر هذا الملف أو ملف `.env`.

## الملفات

- `dist/index.html`: هيكل الواجهة العربية.
- `dist/style.css`: تصميم متجاوب للجوال والحاسوب.
- `dist/app.js`: النوافذ والتصفية والتسجيل وربط API.
- `dist/events.js`: أمثلة تُنسخ إلى قاعدة البيانات في أول تشغيل. بعد ذلك، تعديل السباقات من لوحة الأدمن، ولا يكفي تعديل هذا الملف لتغيير قاعدة البيانات.
- `dist/admin.html` و`dist/admin.js` و`dist/admin.css`: صفحة الدخول ولوحة الإدارة.
- `server/auth.cjs`: تجزئة كلمات المرور وجلسات المدير.
- `server/setup-admin.cjs`: إنشاء حساب المدير أو إعادة ضبط كلمة مرور حساب موجود. التغيير يلغي جلساته السابقة.
- `dist/config.js`: عنوان API إذا كانت الواجهة والخادم منفصلين. الخادم الحالي يقبل نفس الأصل فقط.
- `server/server.cjs`: API وقاعدة البيانات ومهمة التذكير.

رابط المعاينة المستضاف واجهة فقط: لا يحفظ أي تسجيل ولا يرسل رسائل. عند تشغيل المشروع بالخادم يعمل حفظ التسجيل فعليًا. ماراثون عرّابة في هذه النسخة بتاريخ 14.11.2026 بتنظيم جمعية أمانينا؛ الصور والفيديوهات من الملفات التي شاركها صاحب المشروع.

## API

- `GET /api/health`
- `GET /api/events`
- `POST /api/registrations`: eventId, name, email, phone, distance, emailConsent, whatsappConsent.
- `POST /api/auth/login`: username, password.
- `GET /api/auth/me`: جلسة المدير الحالية.
- `POST /api/auth/logout`: تسجيل خروج وإلغاء الجلسة.
- `GET /api/admin/registrations`: يتطلب جلسة مدير.
- `GET /api/admin/events`، `POST /api/admin/events`، `PUT /api/admin/events/:id`: إدارة السباقات.
- التعديلات المحمية تتطلب `X-CSRF-Token` المستلم عند الدخول. الجلسة محفوظة في Cookie من نوع HttpOnly وSameSite=Strict، ومدتها 8 ساعات.
- `GET /cancel?token=...`: صفحة تأكيد؛ الإلغاء نفسه عبر POST.

لوحة الأدمن تتيح إضافة السباقات وتعديلها وعرض المشاركين. تُحفظ السباقات في SQLite وتظهر للزوار من API. لا يمكن إزالة مسافة فيها مشاركون، أو تغيير موعد سباق أُرسلت له تذكيرات بالفعل. يوجد أنيميشن قصير لشعار «Run Msafat» مع احترام تفضيل تقليل الحركة. لا يوجد حساب/كلمة سر للمشارك؛ التسجيل مباشرة في السباق. الدفع عبر PayPal متاح بعد إعداد حساب المنظّم.

## تفعيل الرسائل

البريد: أنشئ حساب Resend، تحقّق من نطاق الإرسال، واضبط `RESEND_API_KEY` و`EMAIL_FROM` و`PUBLIC_URL`.
واتساب: حساب WhatsApp Business Platform، رقم إرسال، token للخادم، وإصدار Graph API مدعوم. جهّز قالب utility معتمد بخمسة متغيرات بالترتيب المذكور في `.env.example`، ثم اضبط متغيرات WHATSAPP.

السيرفر يفحص كل دقيقة ويرسل للتسجيلات الموافق عليها خلال الـ48 ساعة السابقة للسباق. إذا كان التسجيل بعد بداية هذه الفترة يُرسل في الفحص التالي. إذا تأخر تشغيل السيرفر فالتذكير متأخر أيضًا. يجب إبقاء الخادم يعمل باستمرار. لا يُرسل بعد بدء السباق. لكل قناة حالة إرسال منفصلة؛ الاستجابة الناجحة من المزوّد تعني قبول الرسالة وليست تأكيد وصولها.

لا توجد رسائل تأكيد تسجيل فورية حاليًا؛ يظهر تأكيد على الشاشة. البريد يتضمن رابط الصفحة الخاصة بالمشارك. بعد التسجيل احفظ رابط صفحتك؛ يتيح تعديل بياناتك وإلغاء مشاركتك وبطاقة QR. لا تشاركه لأنه مفتاح الوصول إلى بياناتك.

أخطاء 429 و5xx يعاد إرسالها حتى 5 محاولات. أخطاء الاتصال الغامضة تُعلّم failed لتجنب إرسال واتساب مكرر دون تأكد. إعادة التشغيل بين قبول المزوّد وتسجيل sent قد تُكرر رسالة واتساب؛ الإنتاج يحتاج queue/outbox وwebhooks ومعالجة وصول متقدمة. Resend يستخدم مفتاح idempotency ثابت للتذكير.

هذه بداية قابلة للتطوير. قبل فتح تسجيل عام: استخدم HTTPS، صورًا مرخّصة، حماية CAPTCHA، نسخًا احتياطية، وسياسة خصوصية مناسبة. كلمات المرور مخزنة كتجزئة scrypt مع salt عشوائي. لا توجد استعادة كلمة مرور عبر البريد أو صلاحيات متعددة؛ يمكنك إعادة الضبط محليًا بالأمر npm run setup. في الاستضافة استخدم HTTPS وNODE_ENV=production لتفعيل Secure Cookie. يجب حماية الخادم ومراجعة أمانه عند إضافة الدفع أو إدارة حسابات.

## تحديث نسخة سابقة

أوقف الخادم بـCtrl+C. استبدل ملفات `dist` و`server` و`package.json` من هذه النسخة، مع الإبقاء على مجلد `data` وملف `.env` لديك. شغّل `npm install` ثم `npm start`. استخدم `npm run setup` فقط لإنشاء حساب الأدمن لأول مرة أو لإعادة ضبطه. قاعدة البيانات القديمة تُضاف إليها الجداول الجديدة تلقائيًا دون حذف التسجيلات. مفتاح ADMIN_TOKEN القديم لم يعد مستخدمًا.

الأرشيف الجديد يحتوي الملفات مباشرةً؛ بعد فك الضغط شغّل الأوامر من المجلد الذي يظهر فيه package.json، وليس من مجلد أعلى منه.

## العربية والعبرية والإنجليزية

اختر اللغة من القائمة أعلى الموقع؛ يُحفظ الاختيار على نفس المتصفح بين الصفحات. العربية والعبرية من اليمين لليسار والإنجليزية من اليسار لليمين. تشمل الترجمة الواجهة، التسجيل، صفحة الدخول، لوحة الإدارة ورسائل API. تبقى علامة «Run Msafat» باسمها.

السباقات النموذجية مترجمة. لإضافة سباق جديد، افتح «ترجمات السباق» في نموذج الأدمن وأدخل الاسم والمكان والوصف بالعبرية والإنجليزية. إذا تركت ترجمة فارغة يظهر المحتوى الأصلي لذلك الحقل. لا توجد ترجمة آلية لبيانات المنظّم.

تُحفظ لغة المشترك مع التسجيل. البريد يستخدم هذه اللغة عند تفعيل الخدمة. واتساب يحتاج قوالب utility معتمدة منفصلة: WHATSAPP_TEMPLATE_HE وWHATSAPP_TEMPLATE_EN وأكواد اللغة المقابلة. بدون قالب اللغة تبقى رسائلها معلّقة ولا تُرسل بلغة أخرى. قوالب واتساب تستخدم متغيرات الاسم، اسم السباق، الموعد، المكان والمسافة بالترتيب نفسه. إعداد الخدمات لا يزال مطلوبًا للإرسال الفعلي.

`dist/i18n.js` يحتوي قاموس الترجمات ويُستخدم على الواجهة والخادم. قاعدة بيانات النسخة السابقة يُضاف إليها حقل اللغة تلقائيًا، والتسجيلات السابقة تبقى بالعربية. احتفظ بمجلد data وملف .env عند التحديث، وأعد تشغيل الخادم بعد استبدال الملفات.

## Run Msafat — النسخة 1.4.0
### إنشاء ماراثون ورفع صور
شغّل الخادم وسجّل الدخول من admin.html. اختر إضافة سباق، أدخل الاسم والمكان والموعد والمسافات، ثم إضافة صور. انتظر انتهاء الرفع واضغط حفظ السباق. يمكنك تعيين صورة الغلاف أو إزالة ارتباط الصورة بالسباق. لا يتم حذف الصورة الأصلية من التخزين عند فك ارتباطها.
- حتى 6 صور لكل سباق، JPG/PNG/WebP، 5 MB للصورة. لا يُسمح برفع SVG أو HTML. يتحقق الخادم من توقيع نوع الملف وحجمه، وليس من اسم الملف فقط.
- الصور الأصلية في DATA_DIR/uploads؛ قاعدة SQLite تحتوي سجلات الصور وروابطها وعلاقتها بالسباقات. يتم إرسال الصور كملفات متدفقة، ولا تُحمّل داخل سجلات المشاركين.
- الصور تظهر في بطاقات السباقات ومعرض صفحة التسجيل.
- إجمالي المشاركات وعدد المشاركين لكل سباق يستثني التسجيلات الملغاة؛ العدد يحصي مشاركات السباقات، وليس الأشخاص الفريدين عبر جميع السباقات.
- قائمة المشاركين فيها بحث بالاسم أو البريد أو الهاتف، وتصفية حسب السباق و50 سجلًا في الصفحة.
- لوحة الإدارة العامة لا تعمل في المعاينة المستضافة الثابتة؛ الخادم المرفق يفعّل رفع الصور وقاعدة البيانات والدخول.

### ما الذي تغيّر لتحمّل آلاف السجلات؟
- فهارس على السباق وحالة التسجيل وتاريخ التسجيل، وعلى طابور التذكير.
- التجميع وعدّ المشاركين يتمان في قاعدة البيانات، والواجهة تطلب صفحة واحدة بدل جميع السجلات.
- جدولة التذكيرات تجلب 200 رسالة مستحقة في كل دورة، و4 طلبات إرسال متوازية كحد أقصى؛ عند غياب إعداد مزوّد قناة معيّنة تبقى رسائلها معلّقة.
- رفع الصور محدود بطلبين متزامنين على الخادم و5 MB لكل طلب؛ توصي الاستضافة بوضع حد للجسم أيضًا في الوكيل.
- حد التسجيل 300 طلب في الدقيقة لكل IP، مع مهلة للطلبات. إذا وضعت الخادم خلف وكيل موثوق، يجب أن يكتب الوكيل X-Real-IP بنفسه، وبعدها فقط فعّل TRUST_PROXY=1. لا تفعّل هذا الخيار عند الوصول المباشر.
- قاعدة SQLite تعمل بوضع WAL. هذه النسخة مخصصة لعملية Node واحدة وقاعدة محلية على قرص دائم؛ لا تشغّل عدة نسخ من عامل التذكير حتى لا تتكرر الرسائل.

### نتيجة اختبار التطوير
اختبار محلي بتاريخ 2026-10-04: قاعدة تضم 10,000 تسجيل مُضاف في معاملة اختبار، ثم 100 طلب تسجيل API متزامن نجحت جميعها. جلب صفحة من 50 سجلًا استغرق قرابة 5 ms، ودفعة التسجيل قرابة 114 ms في بيئة التطوير. هذه أرقام اختبار محدد وليست ضمانًا لاستضافة أو جمهور حيّ. تم التحقق أيضًا من رفع الصورة ورفض الأنواع والأحجام غير المسموحة، CSRF، حفظ الصور والعدادات بعد إعادة التشغيل، البحث والإلغاء ومنع التسجيل المكرر.

### تشغيل حقيقي
استخدم Node.js 24+ وخادمًا يعمل باستمرار، HTTPS وقرصًا دائمًا. احتفظ بـ DATA_DIR كاملًا عند التحديث: قاعدة البيانات والصور وملفات WAL ذات الصلة. أنشئ نسخًا احتياطية متسقة بوسيلة SQLite backup مع نسخة ملفات الصور، أو أوقف الخادم قبل نسخ مجلد data كاملًا. لا تستبدل بياناتك عند فك النسخة الجديدة.
اختبر على الاستضافة الفعلية قبل فتح التسجيل. آلاف المشاركين المسجّلين تختلف عن آلاف طلبات الكتابة في اللحظة نفسها؛ عند الحاجة إلى عدة خوادم أو ضغط كتابة أكبر، يلزم نقل قاعدة البيانات إلى PostgreSQL وتخزين الصور إلى خدمة ملفات واستخدام طابور إرسال مستقل. هذا النقل غير منفّذ في هذه النسخة.

GET /api/admin/registrations يعيد الآن كائنًا يحتوي items,total,totalActive,page,pageSize,pages. خيارات البحث: page,q,eventId. POST /api/admin/uploads يستقبل بيانات الملف الثنائية مع جلسة الأدمن وX-CSRF-Token ويعيد id,url. إنشاء/تعديل السباق يقبل imageIds مرتّبة؛ الأول هو الغلاف.

## النسخة 2.0.0 — تنظيم السباق والمشاركين

- تسجيل المتطوعين، ست مهام افتراضية، وفرق قابلة للتعديل مع مسؤول ونقطة عمل ووقت بدء وانتهاء وعدد مطلوب. المهام: الاستقبال، الأرقام، المسار، المياه، النهاية، الإسعاف. تعيين الإسعاف يتطلب أن يتحقق الأدمن من التأهيل؛ اختيار المتطوع للتأهيل لا يكفي. من لوحة المتطوعين اختر السباق، أنشئ الفرق ثم وزّع المتطوعين وسجّل حضورهم، وصدّر خطة العمل بصيغة Excel.
- سعة مستقلة لكل مسافة، قائمة انتظار وترقية تلقائية عند توفر مكان. تسجيل مجموعات حتى 30 مشاركًا في طلب واحد، مع بيانات وموافقة كل مشارك؛ احصل على موافقة ولي الأمر عند الحاجة. إذا لم تتوفر أماكن للمجموعة تنتظر المجموعة معًا.
- رقم مشاركة وبطاقة QR، تأكيد حضور عبر الكاميرا أو الرقم في لوحة الأدمن. الكاميرا تتطلب HTTPS أو localhost وإذن المستخدم. رابط المشارك الخاص يحفظ في جزء الرابط بعد #؛ لا ترسله للآخرين. رمز الحضور مختلف عن مفتاح الصفحة الخاصة.
- صفحة تفاصيل السباق: عد تنازلي، المقاعد، خريطة، نقاط مياه، ألبوم وصور رعاة. يرفع الأدمن الصور ويحفظ بياناتها في SQLite؛ الملفات على القرص الدائم. المسار يدخله الأدمن بصيغة نوع,خط عرض,خط طول,اسم نقطة، مثل start,32.52,35.15,خط البداية. الأنواع start/finish/water/point. تحقق من المسار قبل نشره؛ الخرائط تعتمد اتصالًا بخدمة OpenStreetMap.
- نتائج بعد بدء السباق، ترتيب لكل مسافة وفئات عمرية أقل من 18 و18–39 و40+، وشهادة PDF للمشارك بعد نشر نتيجته. أسماء المشاركين وأرقامهم ونتائجهم المنشورة عامة؛ البريد والهاتف خاصان بالأدمن والمشارك. لوحة الإحصاءات وتصدير Excel تدعمان مراجعة التسجيلات. حد الملف 50,000 سجل؛ اختر السباق لتصدير مجموعة أصغر عند تجاوز الحد.

### الدفع
انسخ .env.example إلى .env واضبط PAYPAL_CLIENT_ID وPAYPAL_SECRET وPUBLIC_URL. وضع PAYPAL_MODE=sandbox هو الافتراضي؛ استخدم حسابات اختبار PayPal أولًا. بعد التحقق من حسابك التجاري غيّر الوضع إلى live مع مفاتيح الحساب الحقيقي وHTTPS. السعر بوحدة الشيكل ILS؛ يدخل الأدمن السعر بالشيكل ويخزنه الخادم بالأغورات. بيانات البطاقات لا تُجمع في هذا المشروع. يتحقق الخادم من المبلغ والعملة ومعرّف المشاركة قبل تثبيت الدفع. لا يسمح بتسجيل سباق مدفوع إذا لم تُجهّز الخدمة.

المقاعد تُحجز للمشاركات التي تنتظر الدفع. لا توجد مهلة تحرير تلقائية للحجز غير المدفوع؛ يراجع الأدمن هذه التسجيلات ويلغي غير المدفوع منها. الدفع ذو الحالة الغامضة يبقى للمراجعة حتى التحقق مع PayPal ولا يحرر مقعده تلقائيًا. الإلغاء بعد الدفع يسجل الحاجة إلى استرداد، لكنه لا ينفّذ استردادًا تلقائيًا؛ ينفّذه المنظّم من حسابه بعد المراجعة. لا توجد معالجة webhooks أو تسوية مالية آلية في هذه النسخة.

### التحديث والتحقق
احتفظ بمجلد data وملف .env قبل فك التحديث. ثبّت الحزم باستخدام npm install؛ لا تعِد إنشاء حساب الأدمن الموجود إلا إذا أردت تغيير كلمة مروره. الترحيل يضيف الجداول والحقول ويحافظ على التسجيلات السابقة.
اختُبرت السعة مع طلبات متزامنة، وترقية الانتظار، وتسجيل المجموعات دون حفظ جزئي، وصلاحيات المشارك، والحضور المتكرر، وتوزيع المتطوعين والتحقق من الإسعاف، والنتائج والفئات والشهادة المؤهلة، وملفات XLSX الفعلية. اختُبر مسار الدفع بمزوّد وهمي؛ لم تُخصم أموال ولم تُرسل رسائل. يلزم اختبار PayPal والكاميرا والبريد وواتساب على استضافتك قبل فتح التسجيل الحقيقي.

## SMS — النسخة 2.1.1
أضيف خيار موافقة واضح لولي الأمر: رسالة تأكيد SMS بعد التسجيل وتذكير قبل موعد الانطلاق بـ24 ساعة. البريد والتذكيرات الأخرى اختيارية، ولا يوقف غياب مفاتيح SMS حفظ التسجيل. الرسائل تُحفظ في طابور قاعدة البيانات وتبدأ محاولة التأكيد بعد الحفظ مباشرة، ثم يُراجع الطابور كل دقيقة. يبقى التذكير مؤجّلًا إلى أن يحدد الأدمن ساعة الانطلاق؛ التسجيلات خلال آخر 24 ساعة تُذكّر في الدورة التالية. إلغاء المشاركة يمنع رسائلها غير المرسلة.

لتفعيل الخدمة ضع TWILIO_ACCOUNT_SID وTWILIO_AUTH_TOKEN في .env، وأحد TWILIO_MESSAGING_SERVICE_SID أو TWILIO_FROM من حساب Twilio ثم أعد تشغيل الخادم. الإرسال خدمة SMS خارجية مدفوعة؛ يحتاج حسابًا ورصيدًا وصلاحية الإرسال إلى أرقام المشاركين. حسابات التجربة قد تتطلب التحقق من أرقام المستلمين. مرجع الربط الرسمي: https://www.twilio.com/docs/messaging/api/message-resource

لوحة الأدمن تعرض حالتي التأكيد والتذكير: queued انتظار، sending إرسال، accepted قبلها المزوّد، failed فشل، unknown نتيجة غير مؤكدة، expired انتهى الموعد أو أُلغي التسجيل. accepted لا تعني تسليمًا مؤكّدًا للهاتف؛ لا توجد webhooks لتأكيد الوصول في هذه النسخة. تعاد محاولة الخطأ الصريح 429 حتى 5 مرات؛ أخطاء الاتصال والمهلات و5xx لا تُرسل تلقائيًا مرة أخرى لتجنب التكرار الغامض، وتحتاج مراجعة سجلات المزوّد. كل رسالة لها مفتاح مستقل لمنع إرسالها مرتين في التشغيل الطبيعي؛ لا تشغّل أكثر من عملية Node على نفس القاعدة.

لا تحتوي الرسائل على الهوية أو المدرسة أو نص الإقرار الطبي. تصل إلى هاتف ولي الأمر بعد موافقته، وباللغة التي اختارها. هذه الموافقة لا تتحقق من ملكية الهاتف آليًا. التفعيل لأول مرة قد يرسل تأكيدات التسجيلات السابقة التي وافقت على SMS وما زال سباقها قادمًا؛ راجع الطابور قبل إضافة مفاتيح الحساب الحقيقي.

## تجربة البريد الحقيقي عبر Brevo
1. أنشئ حسابًا في https://www.brevo.com/ ووثّق عنوان المرسل في إعدادات Senders.
2. انسخ `.env.example` إلى `.env` وضع مفتاح API في `BREVO_API_KEY` وعنوان المرسل الموثق في `EMAIL_FROM`. لا تشارك المفتاح ولا تضعه في ملفات الواجهة.
3. اضبط `PUBLIC_URL=http://localhost:3000` للتجربة المحلية؛ الروابط المحلية لا تفتح من جهاز آخر. استخدم رابط السيرفر العام عند النشر.
4. شغّل `npm install` ثم `npm start`. سجّل ببريدك الحقيقي وفعّل موافقة البريد.
تأكيد التسجيل يُرسل بعد الحفظ، والتذكير خلال آخر 24 ساعة عند تأكيد ساعة السباق. دون مفتاح صحيح تبقى الرسائل معلقة. الخطة المجانية محدودة بـ300 إرسال يوميًا؛ تجاوز الحد يؤجل المحاولة ولا يضمن وصول الجميع قبل السباق. قبول الطلب من المزود لا يثبت الوصول؛ افحص الوارد والرسائل غير المرغوب فيها. رابط المعاينة الثابت لا يشغّل إرسال البريد؛ شغّل مشروع Node.
